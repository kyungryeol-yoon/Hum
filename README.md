# Hum

맥의 부하(CPU·메모리·GPU)를 메뉴 막대의 작은 칩 아이콘 하나로 보여 주는 앱입니다. 아이콘을 누르면 자세한 상태와 「지금 무엇이 맥을 바쁘게 하는지」를 보여 줍니다.

> 아직 만드는 중입니다.

## 이름

**Hum**은 영어로 기계나 컴퓨터가 일할 때 내는 낮은 「웅웅」 소리입니다. 영어에서 *humming along*은 「순조롭게 잘 돌아가고 있다」는 뜻이라, 내 맥이 잘 돌아가고 있는지 지켜보는 앱의 이름으로 골랐습니다.

## 기능

- **메뉴 막대 칩 아이콘** — 칩 안쪽 색으로 맥이 얼마나 바쁜지 보여 줍니다(CPU·GPU 중 더 바쁜 쪽 기준). 여유로우면 초록, 바쁠수록 주황을 거쳐 빨강. 옆에 숫자를 붙일 수도 있습니다
- **누르면 뜨는 창**
  - 지금 상태 한마디와 최근 바쁜 정도 그래프
  - CPU(사용자·시스템·대기) · 메모리(압박·스왑·앱/고정/압축) · GPU
  - 저장 공간 막대 · 네트워크(연결 종류, 내부 IP, 받기·보내기 속도) · 배터리(있는 맥만) · 발열 상태
  - 많이 쓰는 프로그램 3개 — 도우미 프로세스는 앱 하나로 묶고, 마우스를 올리면 종료할 수 있음
  - 잠자기를 막는 프로그램
- **설정** — 아이콘 옆 숫자, 갱신 간격(1·2·5초), 로그인할 때 자동 실행
- 가볍게 — 창이 닫혀 있을 때 CPU 1% 미만

## 빌드

```sh
./build.sh           # build/Hum.app
./build.sh install   # 응용 프로그램 폴더에 설치하고 실행
```

## 요구 사항

- 애플 실리콘 맥, macOS 15 이상
